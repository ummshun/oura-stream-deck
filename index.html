Oura, at a glance.

A personal local integration that shows my daily Oura Readiness, Sleep, and Activity scores on Stream Deck.

Data boundary

The integration requests only Oura’s daily permission. It does not request heart rate, location, personal profile data, workouts, tags, or blood oxygen data.

This website has no analytics, forms, cookies, or account system. Oura authorization credentials and the short-lived score cache stay on my own Mac.
