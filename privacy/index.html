Privacy Policy

Purpose

Oura Stream Deck is a personal, local-only integration operated by Shun Matsubara. It displays my daily Oura Readiness, Sleep, and Activity scores on my own Stream Deck.

Data accessed

The integration requests the Oura daily OAuth permission only. It reads the daily Readiness, Sleep, and Activity scores required for the display. It does not request personal profile data, heart rate, workout, tag, session, SpO2, stress, or heart-health permissions.

Storage and sharing

OAuth credentials are stored only in the macOS Keychain on my Mac. Daily scores are cached locally for up to 15 minutes with owner-only file permissions. No Oura data is sent to this website, sold, shared with third parties, used for advertising, or used to train models.

Deletion and revocation

I can revoke the Oura connection from the Oura Developer Portal and delete the local Keychain entry and local cache at any time. The website itself does not keep user accounts or submitted data.

Personal project. Not medical advice.
